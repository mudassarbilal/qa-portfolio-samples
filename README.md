# QA Portfolio Samples

A collection of sanitized, fictional sample deliverables demonstrating my manual QA and localization QA (LQA) documentation style and testing methodology.

> **Note:** All data, product names and tester names in these samples are fictional. No real client, project, or NDA-covered information is included.

## What's Included

- **`sample-bug-report.md`** — A detailed bug report showing structure: summary, repro steps, expected vs. actual results, and severity/priority justification.
- **`sample-test-case-template.md`** — A test case documentation template used for organizing and executing test suites.
- **`sample-lqa-end-report.md`** — An end-of-cycle localization QA report combining a TL;DR, identified patterns, and a tester scoring summary — the format I use to compile multi-tester evaluation runs into a single client-ready deliverable.
